## 第二步：逐张读图（硬规矩）

1. **一张一张读完**，读完后**报出总数**："你发了 N 张，我逐张读完了"——有过漏读事故，必须显式确认。
2. 注意**分页与滚动重叠**：同一页头尾截图会重叠，去重后报实际岗位数。
3. 注意**筛选条件与搜索框**：截图可能带城市/类型筛选切片，会漏掉运营岗。**必须提醒用户把筛选条件清空再看一遍**（思必驰教训：默认视图看不到职能类）。
   - 🔴 **搜索框关键词同样会切片**（长安汽车教训：用户搜"运营"未清空，页面底部有「没有更多了~」看着像完整列表，实为搜索结果 —— 官方 500 个岗位只看到 50 个）。**识别信号：岗位标题里出现黄色/浅色高亮的关键词**（搜索命中高亮）→ 立刻判定"这是搜索/筛选结果，不是全量"，要求清空后重截。
   - **对账的第三处用「招聘官网自己列表页的标题数」**：①页面标题岗位数 ②分页页数×条数 ③逐张去重数——**这三处是同一口径（岗位数）**，对不上就是漏读/漏截。
   - ⚠️ **别把"需求人数"当"岗位数"**：高校就业网的「招聘岗位数」字段**经常填的是需求人数**（长安写 500 实为"智能网联研发类 需求人数 500"，北汽写 1700 实为"招聘人数 1700"）。**51 个岗位 × 平均十来人 ≈ 500 人**，二者不矛盾。看到"官方岗位数"与页面数差几倍时，**先分辨它是人数还是岗位数**，不能直接相除；**以官网列表页标题 + 逐张去重数为准**，高校口径只作参考。（教训：曾据此误判"用户只看到 1/10"，白让他重截一次。）
4. 底部若有"没有更多了"，说明是完整列表；若有分页控件，**提醒用户还有第 N 页没截**。
5. 🔑 **岗位计数交叉核对（2026-09-28 新增，高价值）**：把三个数字对账——①**页面标题的岗位总数**（如心动「开启新的工作（40）」）②**官网分类导航的计数**（如掌趣官网写"策划类 共5个 / 运营类 共6个职位"）③分页控件页数×每页条数。任一处与"我数出来的岗位数"不符，就说明**截图没覆盖全**，必须明确告诉用户漏了多少、漏在哪一类，并让他回去点开那个分类补截。
   - 正例：心动标题 40、4 页×10 条 = 40，与我数出的一致 → 可自信宣布"读全了"。
   - 反例：掌趣官网"运营类共 6 个职位"，截图只露出 2 个（且都是海外岗）→ **真正的机会可能就在没看到的 4 个里**，绝不能凭截图直接下"没有合适的运营岗"结论。
6. 🔍 **截图可能不含公司名和 URL**（顶部/浏览器栏被裁）→ **先从截图里的线索反推公司，再搜 JD**。可用指纹：①**工作城市下拉框的城市组合**（如"福州/上海/北京/成都/雅加达"）②**职能分类的特殊命名**（如 IGG 独有的"**运营（含市场）类**"）③**具体岗位名 + 分类 + 城市的组合**（拿去搜往往能直接命中官网招聘页）。定位后用该公司官网/BOSS直聘的公司介绍交叉验证（如"某集团在 A/B/C/D 均设有全资子公司"）。
   - 若线索不足无法定位，**直接问用户"这是哪家"**，不要硬猜、更不要猜错公司后按错的行业标准筛。

**官网 SPA（北森/zhiye、moka）直接 WebFetch 抓不到内容**——只能拿到标题。改用这些第三方职位库反查 JD：

| 站点 | 命中场景 |
|---|---|

| `o-hr.com`（圆才网） | 苏州/长三角岗位，含**截止日期**和招聘人数 |
| `nowcoder.com` | 内推码、员工发帖、笔试情报 |
| `campus.niuqizp.com` | 招聘批次/时间/城市汇总 |
| 高校就业网（`career.*.edu.cn`、`eie.scu.edu.cn`、`*bysjy.com.cn`、`*91job.org.cn`） | 官方公告原文，专业/学历/流程最准，**且常带内推码** |
| 企业**自建招聘站**（如 `cn-jobs.igg.com`、`u.4399.com/hr`、`hr.xtgame.com`） | 比 SPA 页面好抓，**JD 正文常可直接搜到**（`site`内的 `careers-info.html?id=` / `job?id=` 页面） |
| `waiyupai.com`（外语派） | **海外岗 / 小语种岗 JD 全文**（语言门槛写得最明确） |

| `zhipin.com`（BOSS直聘）/ `liepin.com` | 公司介绍（**含分子公司城市分布**，可反查公司）、社招岗 JD |

**关键招数：北森（zhiye/beisen）系统的页面加 `?KeyWords=` 参数会被搜索引擎收录完整 JD 正文**。直接 WebFetch 官网 SPA 只能拿到标题，但搜 `<公司>.<域名>/jobs?KeyWords=` 或搜岗位名，往往能命中带完整 JD 的官方页面（如思必驰 `aispeech.zhiye.com/jobs?KeyWords=` 直接返回了商务管培生的完整工作职责与任职资格）。

搜索词模板：`<公司> <岗位名> 岗位职责 任职要求`、`<公司> 2027届 校园招聘 内推码`、`<公司> <岗位名> 校招 要求`。

### ⚠️ 搜到 JD 后必须做的两道校验（2026-09-28 新增）

**① 看 JD 里的"经验年限"**——这是判断"校招岗 vs 社招岗"最快的信号：
- 要求"1 年以上/3 年以上/5-10 年"经验 → **社招岗**，应届投进去也大概率被卡，要明确告知用户。
- 写"经验不限/不限经验"或明确标"应届生校招/校园招聘" → 才是他该投的。
- 反例（友谊时光）：官网市场运营类标签下的「活动运营」JD 要求"1 年及以上游戏活动运营经验"、「公关媒介」要求"媒体或公关行业 3 年以上" → 说明该页面是**社招池**，不能当校招批次来筛。

**② 看 JD 详情页 URL 里的日期戳 / 页面发布日期**——判断 JD 是否已过期：
- 例：友谊时光官网 JD 的 URL 是 `friendtimes.net/market/**20191209**/xxx.html` → **2019 年 12 月发布的旧 JD**，不能拿它当现行标准。
- 同理，岗位列表页要留意每个岗位后面的"**发布日期**"（如掌趣列出 2025-08-11 ~ 2026-09-24 两个岗位，差了整整一年 → 这个列表是混编的长期在招池，不全是新批次）。

**③ 顺带判断"这家到底有没有 2027 届校招"**：如果两轮搜索都找不到该公司的 2027 届校招公开公告（高校就业网、牛客、niuqizp 都没有），**不要就此断定"没有校招/是社招池"**——这会判断错。

- 🚨 **友谊时光教训（2026-09-29）**：我因为搜不到校招公告，就下了"这批疑似社招池、没有 2027 届校招"的结论，用户随即发来该公司的「**校园招聘**」专页截图，直接打脸。**有些公司的校招只挂在自己官网，根本不在高校就业网/牛客发公告。**
- ✅ **正确判据（按可靠性排序）**：
  1. **看招聘官网有没有独立的「校园招聘」入口/导航项**（最可靠）。例：友谊时光 `zp.friendtimes.cn` 是**社招站**（路径 `/society/list.html?t=1`），校招是**另一个独立入口**；公司主站导航通常并列「社招职位」+「校园招聘」两个 tab。
  2. 看**页面自身的校招标识**：标题/logo 旁的"校园招聘"标签、当前高亮的导航项、筛选器维度（校招页常有"职位类别 + 工作城市"双筛选 + 分页）。
  3. 搜高校就业网公告（辅助，但不能作为否定证据）。
- ✅ **发现是校招站后，立刻给出高效补截建议**：校招站的分类往往混着大量美术/技术岗，直接让用户**只勾选"运营类 + 内容/发行类 + 策划类 + 职能类"，取消勾选美术设计类和技术开发类**，一屏就能看全他关心的岗位，比一页页截快得多。
- ⚠️ **同时提醒用户看分页器**：校招站常把美术岗排在第 1 页，真正相关的运营/内容岗在后面几页。

## 第四步：评级与输出（固定格式，不可省）

### 评级（按 `02` 标准）

**目标岗位优先级**：AIGC内容运营 > 内容运营/短视频 > Agent工具·AI工作流 > AI+电商 > 游戏内容运营 > 内容社区 > 数字营销

**明确跳过**：国企 / 银行 / 车企 / 快消管培 / BD / 纯后端 / 纯算法 / 纯硬件 / 纯销售

**城市权重**：杭州最高（有补贴）> 上海/北京中 > 深圳/广州/其他 低
**实习**：只接上海或远程（12 月中旬才离开蓝标）

**扣分项**：要求 3 年以上经验却挂应届通道 / 要求英语作工作语言 / 流程含代码笔试

**匹配度分三档：高 / 中 / 低**

### 🔴 必须前置查的两条投递规则（2026-09-28 新增）

**① 每家允许投几个岗位？提交后能不能改？** —— 各公司差异极大，**这直接决定志愿怎么排**，必须在给建议前查清：

| 公司 | 岗位数限制 |
|---|---|
| 米哈游 | **1 个** |
| 4399 | **1 个**（但有"笔试复活甲"：首考未过，换岗位重投可再考一次，最多 2 次笔试） |
| 库洛游戏 | 2 个，**第一志愿优先** |
| 巨人网络 | 2 个，**提交后不可改岗** |
| 心动 / TapTap | 按项目分别投（心动线 / TapTap 线） |
| 字节、小米等 | 通常 2 个 |

→ 遇到"只能投 1 个"，**必须给出唯一推荐并说明理由**，不能让用户自己选。

**② 这家是"实习转正制"还是"直接发正职 offer"？** —— 金sir 12 月中旬才结束上海蓝标实习，**流程形态直接影响他的时间表能否接上**。
- 心动/TapTap 官方流程：投递 → 笔试&面试 → **实习 Offer** → 毕业前"试炼"（实习考核）→ 正式留用。**投校招岗拿到的第一份 offer 也是实习 offer**（对他反而是好事：可与蓝标无缝衔接）。
- 反过来，有些公司的"实习岗"限 28 届 → 他（27 届）**不能投**，必须逐个看清岗位标题里的届别标注。

## 第五步：内推码查找顺序

2. 没有再联网搜，来源优先级：**高校就业网官方公告 > 牛客在职员工发帖 > 其他**
   - 🔑 **高校就业网往往比牛客汇总帖更全**（2026-09-28 实证）：巨人网络的高校码 `DS4BsQUq`（广西职业师范学院）、4399 的 `nhogz`（江苏24365平台）、库洛的 `XU25YQB` 都是高校就业网给的；牛客汇总帖给的是另一套（`DSpXF2Z9` / `f8zko`）。**两路都搜，互为备份。**
   - 🔑 **飞书招聘系统 URL 里的 `spread=` 参数就是内推码**：如心动 `xd-legacy.jobs.feishu.cn/117745/position/list?...&spread=MYEW6ZE` → `MYEW6ZE` 即推广/内推码。搜到官方投递链接时，**先看 URL 有没有 `spread=` / `recommendCode=` / `code=` 参数**（moka 系统用 `recommendCode=`，如巨人 `?recommendCode=DSpXF2Z9`）。
3. **注意届别**：找到 2026 届的码**不能当 2027 届用**，要标注清楚
4. 很多公司（小米、思必驰）的官方口径是"**找校园大使扫码获取**"，没有公开码 → 直接告知这条路径
5. **有些公司根本没有内推码机制** —— 官方渠道只有微信公众号 + 小红书（如掌趣招聘 / 掌趣游戏）。这种情况**直接说"这家没有内推码，走官方渠道"**，不要为凑数硬找或编造。
6. **区分"内推码"和"网申邀请码"** —— 部分公司（如 4399）另有"校园大使邀请码"，权限**高于**普通内推码：内推码只是"简历优先筛选"，邀请码可"**免简历筛选、直通笔试**"。找到这类信息要优先告知。

## 第六步：投递表单代填（2026-09-29 新增，用户发「投递表单截图」时触发）

场景：用户不发岗位列表，而是发**已经打开的投递表单截图**（字段截图），问"这栏怎么写 / 帮我填"。这是新任务类型——交付物**不是四段筛选输出**，而是一份**可直接复制的填写稿**（写进 md 文件 + 回复里贴核心段落）。

**先做一次岗位实况核对**（表单截图顶部常把岗位名/公司名裁掉）：把 岗位名 / JD 三条 / 薪资 / 城市 / 主体公司 / 截止日期 / 内推码 核实并报出来。
- ⏰ **截止日期必须单独查**：官网常只写"招满即止"，而 WonderCV(`wondercv.com/xiaozhao/`)、UP求职(`upcv.tech`)、今日校招(`hahazhao.com`) 这类三方校招站会记录**具体截止日**（星辉实证：三方记录 2026-10-04，官网只写招满即止）→ 这是最紧的约束，先报给用户。
- 注意同一岗位在不同平台的**名称可能不一样**（星辉飞书页「国内营销专员」= 校招公告里的「市场营销专员」，同一岗），核对时说明，避免用户以为投错。

**交付结构（四段）**：
1. 岗位实况表（上面六项 + 匹配度一句话 + 城市权重是否符合他的偏好，不符合就直说"你自己拍板"）
2. 基本信息字段表 = `字段 | 填什么`；自己填不了的（手机/邮箱）标"自填"；简历命名规范 `<姓名>-<学校>-<岗位>-2027届.pdf`，并提醒换"岗位对口版"简历
3. 开放题 = **直接可复制的成段文字**，每栏 150-300 字，并**同时给"压缩版"**（表单单栏常有字数上限）
4. 提交前检查（内推码参数是否还在、简历第一屏放什么、别吹什么、是否限制投递岗位数）

**开放题四件套写法**：
- 「对我司的了解」→ 用**公开数据五件套**：①上市信息（代码/上市时间）②最新年报的业务结构与增速 ③核心产品线/代表作与累计流水 ④最近一年上线的产品 + 榜单/获奖成绩 ⑤渠道与荣誉。**必须联网核实后再写，禁止凭记忆写产品名和数字**（年份、产品名最容易错）。忌拍马屁，用"我关注到三点"的分析口吻。
- 「为什么申请 / 你的优势」→ **逐条映射 JD**：把 JD 拆成 3 条职责，每条后面挂一段**真实经历**（这里才用 `01-我的档案`）。别写成简历复述。
- 「自我介绍 / 自我评价」→ 150 字三段：身份 + 当前实习 → 一句方法论（如"把一件事拆成流程再做规模"）→ 与岗位的落点。
- 「职业规划 / 为什么选这个城市」→ 1 年 / 2-3 年两段，落点写可验证的能力（如"能独立负责一款产品的阶段营销方案"），不写空话。

**敏感字段处理铁律（2026-09-29 新增）**：表单常出现 `有无补考或重修`、`是否受过处分`、`亲属是否在本司任职` 这类字段。
- 一律 **如实填 + 最小必要**。选"有"不致命，**选"无"才是风险**——这类字段是给**入职材料核验/背调**用的（上市国企/大厂校招普遍要交成绩单，一查就出来）。
- 真实权重 = **信息收集项，不是筛选项**：内容/营销岗看作品集与实习，不卡绩点；真正一票否决的是**校级处分、学术不端**。
- 课程/事由按**教务系统里的全称照抄**，多门用顿号分隔，**不加解释、不卖惨**；解释留到面试口头说或补充说明栏。
- 提醒用户**去教务系统"成绩查询/重修记录"核实**，别凭记忆（背调对不上比挂科本身更麻烦）。

**别吹没玩过的 IP**：严格区分"这家公司做过什么"（可写，来自公开信息）与"我玩过什么"（只能写真玩过的）。金sir 没玩过《三国群英传》系列 → 只能写"熟悉策略/三国题材品类"（《三国杀》《冰汽时代》全成就是真实支撑）；**写了"熟悉该厂 XX"面试必被追问**。

**期望薪资 / 到岗时间标准答法**：
- 期望薪资：必填数字就填岗位区间中位（8-12K → 10K）；可填文字就写"按公司薪酬体系执行"。
- 到岗时间："2026 年 12 月下旬可到岗实习，2027 年 7 月后可全职"（对应他 12 月中旬才结束上海蓝标）。
- 语言水平：CET-6 449 → 国内岗**不主动提分数**，只写"CET-6"。
