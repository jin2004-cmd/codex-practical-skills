# 作品与工程双目录交付

以用户给出的目录为准。作品目录让人一眼找到当前成片；工程目录让另一台电脑或下一位操作者能复现。

| 作品展示目录 | 工程全过程目录 |
| --- | --- |
| 当前版 MP4 | 可运行 src、公用素材、配置和依赖锁文件 |
| 必要封面/展示图 | 原始与加工素材、授权和来源 |
| 简短作品说明/必要署名 | 音效主轨、分轨、cue、生成脚本 |
| 用户明确需要的展示素材 | 验收联系表、机器报告、修改记录、可复用技能 |

旧版放独立历史目录，避免两个文件都叫“最终版”。作品目录不混入 node_modules、审核截图、调试脚本或内部制作注释。

复制完成后比较实际成片的大小和散列，确认不是历史配音版或未完整渲染文件。项目清单写明版本、composition、帧率、分辨率、时长与运行方式；依赖缓存可重建，独有素材和手工加工结果必须保留。

技能包只包含通用规则和必要的可复用脚本/项目示例。外部技能快照保留许可证和来源；私人归档不等于公开分发许可。切勿在“工程全过程”包中夹入 .env、令牌、飞书 webhook 或无关私人记忆。

交付消息首先给可点击成片路径和两个文件夹路径，然后一句话说明改动与验证范围。没有完成完整播放听审时，应据实说明，不能用“全部验收通过”代替。
