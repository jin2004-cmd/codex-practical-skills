# Local context

The project AGENTS.md is the source of truth for the active personal vault, area, and workspace. Do not hard-code a machine-specific drive path in this Skill.

Use the memory index to route:

- current status for continuity and next actions;
- stable notes for durable background and decision principles;
- event logs for dated history or conflicts;
- one relevant topic note for the current task.

Historical exports and other assistant copies are snapshots. Verify paths and source availability instead of assuming recovery.
