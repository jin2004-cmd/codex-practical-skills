# Maintenance and handoff

For each new fact, record the event date, collection date, and source type. Update the canonical current file for changing status, append the event log for evidence, and change stable notes only when durable background or principles changed.

For contradictions, preserve both sources and state which field the newer evidence covers. A collection date does not refresh every historical fact.

For a handoff, export a dated general snapshot and a separate tool/Skill bundle. Keep machine paths, credentials, company data, and local state out of public repositories. The receiving assistant must merge a snapshot into a selected activity vault rather than overwrite it.

The included validator checks only the specified area for note metadata, internal links, Canvas structure, and obvious credential patterns. It has no network access and does not verify the truth of the notes.
